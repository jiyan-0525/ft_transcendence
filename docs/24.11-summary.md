## 4. Routing concepts clarified

- `/login` belongs to the pathless `AuthLayout` branch of the single `createBrowserRouter` route table; `/settings` belongs to the `/` + `AppShell` branch.
- The headers differ because each branch is a layout route with its own `<header>`; React Router keeps the layout mounted and swaps only `<Outlet />`.
- Removing `{ path: '*', element: <NotFoundPage /> }` makes `/nope` unmatched. Because this is a data router with no `errorElement`, React Router shows its built-in **"Unexpected Application Error! / 404 Not Found"** screen — no custom 404 page, no AppShell header, no custom title.

## 5. Database and IDs

- Friend IDs are `users.id` in PostgreSQL. They are **not** stored in `database.py` — that file only creates the SQLAlchemy `engine`, `SessionLocal` and `get_db()` session.
- The column is defined in `packages/server/app/models.py:30` (`id: Mapped[int] = mapped_column(primary_key=True)`) and created by migration `88fd3dcf3c30_create_users_and_sessions.py`.
- Database details (from root `.env` and `compose.db.yml`):
  - container `transcendence-db-db-1`, image `postgres:16-alpine`
  - database `transcendence`, user `postgres`, password `change_me`
  - host `127.0.0.1:5432`, data volume `postgres_data`
  - `DATABASE_URL` is used by `make dev`; `CONTAINER_DATABASE_URL` (host `db`) is used by `make stack-up`
- To inspect rows:
  ```bash
  make db   # or: docker compose -p transcendence-db -f compose.db.yml exec db psql -U postgres -d transcendence
  ```
  Then in psql: `\dt`, `\d users`, `SELECT id, email, username FROM users ORDER BY id;`, `\q`.
- One-shot version:
  ```bash
  docker compose -p transcendence-db -f compose.db.yml exec -T db \
    psql -U postgres -d transcendence -c 'SELECT id, username FROM users ORDER BY id;'
  ```
- In VSCode, the integrated terminal can run `make db`. For a GUI, install **SQLTools** + **SQLTools PostgreSQL/Redshift Driver** and connect to `127.0.0.1:5432`, db `transcendence`, user `postgres`, password `change_me`. With Remote/Dev Container, `127.0.0.1` may point to the wrong machine, so prefer the terminal.
